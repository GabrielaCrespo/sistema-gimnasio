# Requisitos del Sistema

## Objetivo

Desarrollar un sistema web para la gestión básica de un gimnasio que permita administrar usuarios, clientes, instructores, ejercicios, evaluaciones físicas y rutinas de entrenamiento mediante la arquitectura MVC.

## Actores

* **Administrador:** Gestiona cuentas de usuario y configuración básica.
* **Instructor:** Gestiona ejercicios, grupos musculares, evaluaciones y rutinas.
* **Cliente:** Consulta sus rutinas y evaluaciones y actualiza sus datos personales.

## Requisitos funcionales

* RF01: Gestionar el acceso al sistema (iniciar y cerrar sesión).
* RF02: Gestionar cuentas de usuario (crear, consultar, modificar, estado y perfil).
* RF03: Administrar el catálogo de grupos musculares.
* RF04: Administrar el catálogo de ejercicios.
* RF05: Gestionar evaluaciones físicas (registrar y consultar historial).
* RF06: Gestionar rutinas de entrenamiento (crear, asignar, modificar ejercicios y visualizar).

## Requisitos no funcionales

* RNF01: Implementar arquitectura MVC.
* RNF02: Utilizar PHP y PostgreSQL.
* RNF03: Utilizar HTML, CSS y JavaScript.
* RNF04: Desarrollar el sistema sin frameworks.
* RNF05: Controlar el acceso según el rol del usuario.
